# Core Plugins Reference

Core plugins ship with Obsidian and are toggled on or off per vault in Settings → Core Plugins.
They do not require installation and are updated with Obsidian itself.

## Core plugin list

| Plugin | Purpose |
| --- | --- |
| Audio recorder | Record audio notes directly into the vault |
| Backlinks | Panel showing all notes that link to the current note |
| Bookmarks | Save notes, headings, blocks, and searches as bookmarks |
| Canvas | Create `.canvas` visual workspace files |
| Command palette | Quick access to all commands (Ctrl+P / Cmd+P) |
| Daily notes | Auto-create a dated note per day using a template |
| File recovery | Automatic snapshots for recovering recent changes |
| Files | File explorer sidebar panel |
| Format converter | One-time migration from Roam Research or other formats |
| Graph view | Visual graph of note relationships |
| Note composer | Merge notes or extract selections to new notes |
| Outgoing links | Panel listing all links in the current note |
| Outline | Jump-to-heading panel for the current note |
| Page preview | Hover preview of linked notes |
| Properties view | Sidebar panel listing all frontmatter properties |
| Quick switcher | Fast note navigation by title (Ctrl+O / Cmd+O) |
| Random note | Open a random vault note |
| Search | Full-text search with operators |
| Slash commands | Trigger commands with `/` in the editor |
| Slides | Present a note as a slideshow |
| Sync | Obsidian Sync client (requires subscription) |
| Tags view | Browse vault by tag |
| Templates | Insert template files into notes |
| Unique note creator | Create notes with UID-based filenames |
| Word count | Word and character count in the status bar |
| Workspaces | Save and restore pane layout snapshots |

## Enabling a core plugin

Settings → Core Plugins → find the plugin → toggle on.
Most core plugins add a panel icon, a command palette entry, or both after enabling.

## Configuring core plugins

Each enabled core plugin has its own settings page accessible from the left sidebar of Settings.
Key configuration examples:

- **Daily Notes**: set folder, template file, and date format
- **Templates**: set template folder path
- **File Recovery**: adjust snapshot interval and retention period
