
CLI for Microsoft 365 v11.8.0
Manage Microsoft 365 and SharePoint Framework projects on any platform 

Commands:

  cli consent [options]  Consent additional permissions for the Microsoft Entra application used by the CLI for Microsoft 365
  cli doctor [options]   Retrieves diagnostic information about the current environment
  cli issue [options]    Returns, or opens a URL that takes the user to the right place in the CLI GitHub repo to create a new issue reporting bug, feedback, ideas, etc.
